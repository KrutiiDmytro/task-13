# Проект "{Назва вашого проекту, наприклад, 'Блог на Laravel'}"

Це навчальний проект, розроблений в рамках курсу, який демонструє створення простого блогу з використанням фреймворку Laravel. Додаток реалізує базовий функціонал: відображення списку постів, перегляд окремих постів, їх категорій, тегів та коментарів.

## Основні технології

-   **Backend:** PHP 8.1, Laravel 10
-   **База даних:** MySQL
-   **Інструменти:** Composer, Artisan

## Вимоги до оточення

Для запуску проекту на вашому локальному комп'ютері необхідно мати встановлене наступне програмне забезпечення:

-   PHP >= 8.1
-   Composer 2
-   MySQL (або інша реляційна СУБД, сумісна з Laravel)

## Встановлення та запуск проекту

Виконайте ці кроки, щоб розгорнути проект локально:

1.  **Клонуйте репозиторій**
    Відкрийте термінал і виконайте команду:
    ```bash
    git clone {URL-адреса вашого репозиторію на GitHub}
    cd {назва-папки-проекту}
    ```

2.  **Встановіть залежності**
    Використовуйте Composer для встановлення всіх необхідних PHP-пакетів:
    ```bash
    composer install
    ```

3.  **Налаштуйте файл оточення**
    Створіть копію файлу `.env.example` з назвою `.env`. Потім згенеруйте унікальний ключ для додатку.
    ```bash
    cp .env.example .env
    php artisan key:generate
    ```
    Після цього відкрийте файл `.env` у вашому редакторі коду та вкажіть правильні налаштування для підключення до вашої локальної бази даних:
    ```
    DB_CONNECTION=mysql
    DB_HOST=127.0.0.1
    DB_PORT=3306
    DB_DATABASE={назва_вашої_бази_даних}
    DB_USERNAME={ім'я_користувача_бд}
    DB_PASSWORD={пароль_користувача_бд}
    ```

4.  **Виконайте міграції та заповніть базу даних**
    Ця команда створить усі таблиці в базі даних та заповнить їх тестовими даними (постами, категоріями, тегами і т.д.):
    ```bash
    php artisan migrate:fresh --seed
    ```

5.  **Запустіть локальний сервер**
    Тепер ви можете запустити сервер для розробки за допомогою Artisan:
    ```bash
    php artisan serve
    ```

Після виконання цієї команди ваш проект буде доступний у браузері за адресою `http://127.0.0.1:8000`.

## Запуск тестів

Для перевірки працездатності додатку та запуску автоматизованих тестів виконайте команду:

```bash
php artisan test
```
